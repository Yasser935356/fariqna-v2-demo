# فريقنا 2.0 — الموقع التجريبي

هذه نسخة ثابتة للإضافة الأولى: تعديل اسم المساحة ووصفها.
التصميم عربي وبنفسجي وRTL. الحسابات والبيانات وهمية، والحفظ محلي لكل متصفح.
لا توجد مفاتيح أو بيانات حقيقية أو اتصالات بـAppwrite أو اعتماديات خارجية.
لا يوجد خادم حقيقي في هذه المعاينة؛ محاكاة الصلاحيات ليست اختبارًا لصلاحيات قاعدة البيانات المنشورة.

## التجربة

افتح الموقع، ثم المساحة، ثم إعدادات المساحة، وعدّل الاسم والوصف.
أعد التحميل للتحقق من الحفظ. اختر «الدخول كعضو» لرؤية التعديلات واختفاء زر الإعدادات.
البيانات لا تتزامن بين اللابتوب والجوال؛ كل متصفح له تجربته الوهمية المستقلة.
«إعادة البيانات التجريبية» يمسح بيانات هذه المعاينة فقط.
الأزرار الخاصة بالإضافات غير المنجزة لا تنفّذ تغييرات.

## إعداد GitHub Pages

هذا المستودع مستقل عن Yasser935356/fariqna.
المصدر: فرع demo، المجلد /(root)، باستخدام Deploy from a branch.
لا توجد ملفات CNAME أو مسارات عمل تغير الموقع الأصلي.

## التحديث على الرابط نفسه

يولّد المبرمج النسخة من أحدث كود مُراجع بواسطة:
`python3 tools/build-static-demo.py --output /absolute/path/to/fariqna-v2-demo`
(الأمر داخل مستودع التطوير الأصلي.)
ثم يعيد اختبارات الوحدة والتكامل والمتصفح وفحص العزل، ويرفع الملفات الأربعة الناتجة
إلى فرع demo في هذا المستودع فقط. تنشر Pages تحديث الفرع على الرابط نفسه.
لا يتغير اسم المستودع أو إعداد مصدر Pages، ولا يلزم إعادة ضبطهما عند كل إضافة.
ينبغي تجنب تضمين الحزم المؤقتة أو مستودع Git أو ملفات البيئة في الرفع.
الإصدار ظاهر أعلى الصفحة وفي demo-build.json للتحقق من وصول التحديث.
